One emoji, one dream vacation: a desert island 🏝. This program writes exactly one emoji to `/output/entry.txt` for make.fun's "One Emoji, One Dream Vacation" bounty — a lone palm on a faraway island, the postcard for getting away from everything.

## Run it

```sh
python3 main.py
```
